# 校园网自动登录（Windows 零依赖版）

**不需要安装 Python、Node.js、Java，也不需要装任何运行库。**
**拷贝到电脑上，双击就能用。**

一个用于**校园网 Portal 认证**的小工具：开机自动静默登录，断线自动重连，全程无需人工操作。

> 适用于采用 **raas 门户系统**的校园网（接口形如 `/api/login.php`、`/api/stat.php`）。
> 其他门户只需修改配置里的接口路径即可尝试。
需要提前准备好登录校园网时的网址。如"http://10.11.111.1"。/index.html后面一长串都不需要。

## 这个项目是干什么的

很多学校的校园网采用「Portal 认证」：连上网络后，打开浏览器会被跳转到一个登录页面，输入学号密码才能上网。

**这个项目把这个过程自动化了：**

- 电脑开机后，程序自动帮你完成认证
- 全程在后台静默运行，**不会弹窗打扰你**
- 网络断了或者认证失效了，**自动重新登录**
- 你什么都不用管

---

## 核心功能

| 功能 | 说明 |
|---|---|
| ✅ **自动登录** | 开机后自动携带配置好的账号密码完成认证 |
| ✅ **断线重连** | 定时检测网络，掉线或认证失效时自动重新登录 |
| ✅ **开机自启** | 一条命令配置计划任务，登录系统后静默后台运行 |
| ✅ **无窗口运行** | 隐藏窗口方式启动，不弹控制台、不打扰使用 |
| ✅ **配置外置** | 账号密码放在配置文件里，代码中不含任何隐私信息 |
| ✅ **一键卸载** | 自启项可完整移除，不留残余 |
| ✅ **离线自测** | 自带测试工具，不连校园网也能验证程序是否正常 |

## 为什么叫零依赖

这是本项目最大的特点，值得单独说明。

**「零依赖」的意思是：不需要安装任何额外软件。**

| 对比项 | 一般做法 | 本项目 |
|---|---|---|
| 需要装 Python | 常见 | ❌ **不需要** |
| 需要装 Node.js | 常见（用于加密口令） | ❌ **不需要** |
| 需要装运行库 | 可能需要 | ❌ **不需要** |
| 需要 pip / npm 安装 | 可能需要 | ❌ **不需要** |

**它只用 Windows 系统自带的东西：**

| 用到的系统组件 | 说明 |
|---|---|
| PowerShell | Windows 自带的命令行工具 |
| Windows Script Host | 系统自带的小型脚本引擎（用于口令加密） |
| 任务计划程序 | 系统自带（用于开机自启） |
| cmd 批处理 | 系统自带（用于双击运行） |

> **为什么这一点很重要？**
> 因为很多同学照着教程装 Python 时会卡在环境变量、权限、版本冲突上。
> 本项目把这些麻烦全部去掉了。

**唯一的要求**：第一次运行时需要能访问学校门户，
因为程序要下载门户自己的加密脚本（只下载一次，之后缓存在本地）。

## 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | **Windows 10 1709 或更高** / **Windows 11 全部版本** |
| 权限 | **普通用户即可，不需要管理员** |
| 网络 | 首次运行需能访问学校门户 |
| 磁盘空间 | 约 200 KB |

**怎么确认自己的系统符合要求？**

1. 按 `Windows 徽标键 + R`，输入 `powershell`，按回车
2. 在弹出的窗口里输入下面这行，按回车：

```powershell
$PSVersionTable.PSVersion
```

3. 看到 `5.1` 或更高的数字就可以用。

> **Windows 7 / 8 用户注意**：系统自带的 PowerShell 版本太低，本程序无法保证正常运行。
> 建议升级系统。

## 快速上手（三步）

### 第一步：填写你的账号密码

**双击 `setup.bat`**

它会自动：
1. 帮你复制一份配置文件
2. 用记事本打开，让你填写

**只需要改这三项引号内汉字部分**（其余保持默认不要动）：

```json
{
  "portal": {
    "base_url": "这里填你的门户地址"
  },
  "account": {
    "username": "这里填你的学号",
    "password": "这里填你的密码"
  }
}
```

**填写要点：**
| `base_url` | 浏览器打开认证页面时的地址，**结尾不要带 `/index.html`** |

例如将    "base_url": "这里填你的门户地址",
改为      "base_url": "http://10.11.111.1",


**格式提醒（很重要，如果只改了引号内的汉字不用管）：**

- 必须用**英文双引号** `"`，不能用中文引号 `“”`
- 最后一项后面**不要多加逗号**
- 改完按 `Ctrl + S` 保存，然后关闭记事本

### 第二步：先测试能不能登录

确保电脑**已经连上校园网**，然后：

**双击 `status.bat`**，在菜单里输入 **`3`**（尝试登录一次），按回车。

**看到这样的提示就是成功了：**

```
[成功] 认证成功（状态返回码 0）
```

> 如果失败，先看下面的[常见问题排查](#常见问题排查)。

### 第三步：配置开机自动登录

**双击 `install.bat`**

看到 `[OK] Autostart installed` 就完成了。

**最后重启一次电脑验证**：

重启后登录桌面，等大约 1 分钟，双击 `status.bat`，
选择 **`1`** 查看状态，看到下面这行就大功告成：

```
当前能否上网：是
```

## 配置填写教程

完整配置在 `config\config.json`，每一项都有中文注释。这里列出常用的：

### 必填项

| 配置项 | 说明 |
|---|---|
| `portal.base_url` | 你的门户地址 |
| `account.username` | 你的学号 |
| `account.password` | 你的密码（明文） |

### 可能需要调整的项

| 配置项 | 默认值 | 什么时候需要改 |
|---|---|---|
| `portal.query` | 空 | 程序提示返回 `255 / ARG` 时填（见排查第 3 条） |
| `account.pool` | 空 | 学校要求选择运营商线路时填，如 `"1"` |
| `keepalive.check_interval` | `30` | 想更省资源可以改成 `60` |
| `keepalive.offline_trigger` | `2` | 网络经常抖动、误判掉线时改成 `3` |
| `keepalive.connect_test_url` | 微软连通性地址 | 学校内网有更稳定的地址时替换 |
| `crypto.key` | 空 | 留空会自动解析；解析失败时才手动填 |

## 开机自启说明

**双击 `install.bat` 即可**，程序会自动选择最可靠的方式：

### 方式一：计划任务（首选）

- 使用系统自带的 `schtasks` 命令注册
- 触发条件：**用户登录时**
- 运行身份：**当前用户 + 交互式 + 最低权限** → **不需要管理员权限**
- 启动方式：隐藏窗口，**没有弹窗**

### 方式二：启动文件夹（备选）

如果计划任务被**安全软件或公司策略**拦截导致失败，
程序会**自动改用**在启动文件夹放一个启动器（同样是隐藏窗口运行）。

**安装成功时两种方式会同时创建，形成双保险。**

### 如何取消

**双击 `uninstall.bat`**，会同时删除计划任务和启动文件夹项。

### 开机自启没生效怎么办

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 重启后没反应 | 自启项没装上 | 双击 `status.bat` 选 `1`，看「计划任务」是否「已安装」 |
| 已安装但没运行 | 触发条件是「登录时」 | **必须真正登录进桌面**才会启动，属正常现象 |
| 提示拒绝访问 | 被安全软件拦截 | 把项目文件夹加入安全软件白名单 |
| 移动过文件夹 | 自启记录的是绝对路径 | 移动后必须重新双击 `install.bat` |

## 命令说明

一般**双击 `.bat` 文件**就够用了，下面是每个文件的作用：

| 文件 | 作用 |
|---|---|
| `setup.bat` | 创建并打开配置文件，让你填写账号密码 |
| `install.bat` | 安装开机自启，并在后台启动程序 |
| `uninstall.bat` | 卸载开机自启 |
| `status.bat` | **菜单式工具**：查状态、诊断、测试登录、看日志 |
| `check-privacy.bat` | 发布前隐私自检（想开源分享时用） |
| `run-tests.bat` | 离线自测，不连校园网也能验证程序是否正常 |

**如果你想手动运行 PowerShell 命令**（进阶用法）：

```powershell
# 进入项目目录
cd /d 你的项目目录

# 查看当前状态
powershell -ExecutionPolicy Bypass -File lib\main.ps1 -Status

# 网络与门户诊断
powershell -ExecutionPolicy Bypass -File lib\main.ps1 -Diagnose

# 只尝试登录一次
powershell -ExecutionPolicy Bypass -File lib\main.ps1 -Once

# 本地自检（不访问门户）
powershell -ExecutionPolicy Bypass -File lib\main.ps1 -SelfTest

# 前台运行，实时看日志（按 Ctrl+C 退出）
powershell -ExecutionPolicy Bypass -File lib\main.ps1
```

> **关于执行策略**：Windows 默认会限制脚本运行。
> 上面命令里的 `-ExecutionPolicy Bypass` 只对**这一次执行**生效，
> **不会修改你的系统设置**，是微软官方提供的方式。
> 所有 `.bat` 文件里都已经帮你加好了。

## 常见问题排查

**先运行这两个检查，多数问题能直接定位：**

- 双击 `status.bat`，选 `4`（本地自检）
- 双击 `status.bat`，选 `2`（网络诊断）

**日志文件位置**：`data\autologin.log`

### 1. 登录失败

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 提示「找不到配置文件」 | 还没做第一步 | 双击 `setup.bat` |
| 提示「还有必填项没有填写」 | 还是模板里的占位文字 | 按教程填写你的真实信息 |
| 提示「配置文件格式错误」 | JSON 格式写错了 | 检查有没有用中文引号 `“”`、有没有多逗号 |
| 返回码 `4` / `5` | 账号或密码错误 | 核对学号和密码；注意 `@` 这类符号要完整 |
| 返回码 `255` 且提示 `ARG` | 服务端要求附带参数 | 见下面第 3 条 |
| 提示「门户不可达」 | 当前不在校园网内 | 插网线或连校园 WiFi 后重试 |
| 一直显示「认证中」 | 账号欠费，或别处也登录了同一账号 | 检查其他设备是否在用同一账号 |

### 2. 提示需要安装 Node.js？

**不需要。** 本版本已用 Windows 自带的
**Windows Script Host** 替代了 Node.js，全程不需要装任何软件。

如果看到这种提示，说明你用的是旧版本，请使用本版本。

### 3. 返回码 255、提示 ARG

服务端要求请求地址上带 AC（接入控制器）传来的参数。做法：

1. 用**浏览器**在校园网下打开认证页面
2. 把地址栏里 `?` 后面的内容**整段复制**，
   例如：`wlanuserip=网关地址&wlanacname=设备名&nasip=网关地址`
3. 粘贴到配置文件的 `portal.query` 里

### 4. 无法解析出加密密钥

程序会先从门户的加密脚本里自动找密钥。找不到时才需要手动填：

1. 浏览器打开 `<你的门户地址>/assets/js/crypto.js`，保存到本地
2. 用记事本打开，搜索 `parse`
3. 找到形如 `parse('一串十六进制字符')` 的内容，把那串字符复制下来
4. 填到配置文件的 `crypto.key`

> 每所学校的密钥不一样，以你自己门户里的为准。

### 5. 频繁断连、反复重连

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 每隔几十秒就重连 | 探测目标响应慢，导致误判 | 把 `offline_trigger` 改成 `3` |
| 登录成功但马上掉线 | **多设备同时在线**，被服务器互相踢 | 只保留一台设备登录 |
| 掉线后很久才恢复 | 重试间隔太长 | 把 `retry_interval` 改成 `5` |
| 休眠后掉线 | 网卡节能设置 | 在电源选项里关闭网卡节能 |

### 6. 日志文件越来越大

日志已内置自动轮换：超过 1 MB 会自动转为 `autologin.log.1`，最多占 2 MB。
也可以直接删除 `data\autologin.log`。

### 7. 怎么彻底卸载

1. 双击 `uninstall.bat`（移除开机自启）
2. 删除整个项目文件夹

程序**不写注册表、不装系统服务、不修改任何网络设置**，删掉文件夹就干净了。

## 隐私与安全

### 这个程序做了什么

- 只用标准的网络请求模拟浏览器登录行为
- 把自己的日志和缓存写在项目目录的 `data\` 子文件夹里
- 注册一个属于当前用户、可一键卸载的计划任务

### 这个程序不做什么

- ❌ 不修改网卡、驱动、DNS、路由等任何网络设置
- ❌ 不读取、不上传账号密码到任何第三方（只提交给学校门户本身）
- ❌ 不含任何恶意行为、信息窃取、系统破坏逻辑
- ❌ 不弹广告、不捆绑安装
- ❌ 不需要关闭杀毒软件

### ⚠️ 给使用者的重要提醒

`config\config.json` 里是**明文账号密码**（这是自动登录所必需的）。

**请勿把这个文件发给别人，也不要上传到网盘、GitHub 等公开位置。**

本项目已经用 `.gitignore` 帮你屏蔽了这个文件，防止误上传。

### 给想 Fork 或分享的人的提醒

**上传到 GitHub 之前，请先双击 `check-privacy.bat` 做一次隐私自检。**

重点确认这三个：

1. `config\config.json` **没有被上传**（应该是被忽略的状态）
2. 代码和文档里**没有**出现你的真实学号、密码
3. `data\` 目录**没有**被上传（里面有运行日志）

详细步骤见 [docs/github-publish.md](docs/github-publish.md)。
