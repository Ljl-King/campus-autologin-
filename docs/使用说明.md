# 校园网自动登录程序（Windows 零依赖版）

**不需要安装 Python、Node.js、Java 等任何运行环境。**
只用 Windows 系统自带的组件就能运行，拷到电脑上双击即可使用。

---

## 一、系统要求

| 项目 | 要求 | 说明 |
|---|---|---|
| 操作系统 | **Windows 10 1709 或更高** / **Windows 11 全部版本** | 推荐 Win10 1803+ |
| PowerShell | 5.1（系统自带） | 无需单独安装 |
| Windows Script Host | 系统自带 | 用于口令加密，Win7 起全部内置 |
| 权限 | **普通用户即可** | 不需要管理员 |
| 网络 | 需能访问学校认证门户 | 第一次运行需要（用于下载门户加密脚本） |

**检查系统是否符合要求**：按 `Win + R`，输入 `powershell` 回车，然后输入：

```powershell
$PSVersionTable.PSVersion
```

显示 `5.1` 或更高即可。

> ⚠️ **Windows 7 / 8 用户**：系统自带的 PowerShell 版本过低（2.0/3.0），
> 本程序无法保证正常运行。建议升级系统，或参考文末「低版本系统备选方案」。

## 三、使用方法（三步走）

### 第 1 步：填写配置

**双击 `1-初始化配置.bat`**

它会自动：
1. 把 `config\config.example.json` 复制成 `config\config.json`
2. 用记事本打开让你填写

**只需改这三项**（其余保持默认）：

```json
{
  "portal": {
    "base_url": "这里填你的门户地址"          ← 改成你们学校的认证门户地址
  },
  "account": {
    "username": "这里填你的学号",            ← 改成你的学号
    "password": "这里填你的密码"             ← 改成你的密码
  }
}
```

**填写要点：**

| 项目 | 怎么填 |
|---|---|
| `base_url` | 浏览器打开认证页面时的地址，**结尾不要带 `/index.html`** |
| `username` | 学号，纯数字 |
| `password` | **填明文**即可，程序会自动加密后再提交 |

**格式提醒（很重要）：**
- 必须用**英文双引号** `"`，不能用中文引号 `“”`
- 最后一项后面**不要多加逗号**
- 改完按 `Ctrl + S` 保存，然后关闭记事本

### 第 2 步：先测试能不能登录

确保电脑**已连上校园网**，然后：

**双击 `4-查看状态.bat`** 查看当前情况，接着在命令提示符里运行：

```powershell
cd /d 你的程序目录
powershell -ExecutionPolicy Bypass -File lib\main.ps1 -Once
```

> 更简单的办法：双击 `4-查看状态.bat`，选择 `login` 即可。
> 或者在命令提示符里输入：`4-查看状态.bat login`

**看到这样的提示就是成功了：**

```
[2026-01-01 10:00:00] [信息] 提交登录 → 返回码=0 消息=正在认证...
[2026-01-01 10:00:02] [成功] 认证成功（状态返回码 0）
```

### 第 3 步：启用开机自动登录

**双击 `2-安装开机自启.bat`**

看到 `[OK] Auto start installed` 就完成了。

**最后重启一次电脑验证**：重启后登录桌面，等 1 分钟，双击 `4-查看状态.bat`，
看到 **`当前能否上网：是`** 就大功告成。

## 四、开机自启是怎么实现的

程序会自动按可靠性选择方案：

### 方案一：计划任务（首选）

- 使用系统自带的 `schtasks` 命令注册
- 触发条件：**用户登录时**
- 运行身份：**当前用户 + 交互式 + 最低权限** → **不需要管理员权限**
- 启动命令：`powershell.exe -WindowStyle Hidden -File lib\main.ps1 -Quiet`
  （`-WindowStyle Hidden` 保证**没有窗口弹出**）

### 方案二：启动文件夹（备选）

如果计划任务被**组策略或安全软件**拦截导致失败，
程序会**自动降级**为在启动文件夹放一个 `.vbs` 启动器（隐藏窗口运行）。

> 用 `.vbs` 而不是快捷方式，是因为 `.vbs` 是 Windows 原生支持的，
> 零依赖且一定能隐藏窗口。

**安装成功时两种方式会同时创建，形成双保险。**

### 卸载

双击 `3-卸载开机自启.bat`，会同时删除计划任务和启动文件夹项。

## 五、配置项说明

完整配置见 `config\config.json`，每一项都有中文注释。这里列出常用项：

### 必填

| 配置项 | 说明 |
|---|---|
| `portal.base_url` | 门户地址 |
| `account.username` | 学号 |
| `account.password` | 密码（明文） |

### 可能需要调整

| 配置项 | 默认值 | 什么时候改 |
|---|---|---|
| `portal.query` | 空 | 程序提示返回 `255/ARG` 时填（见排查第 3 条） |
| `account.pool` | 空 | 学校要求选运营商线路时填，如 `"1"` |
| `keepalive.check_interval` | `30` | 想更省资源可改 `60` |
| `keepalive.offline_trigger` | `2` | 网络经常抖动导致误判掉线时改 `3` |
| `keepalive.connect_test_url` | 微软连通性地址 | 学校内网有更稳定地址时替换 |
| `crypto.key` | 空 | 留空自动解析；解析失败时才手动填 |

### 命令行参数

| 参数 | 作用 |
|---|---|
| （无） | 前台运行，实时显示日志（调试用，`Ctrl+C` 退出） |
| `-Install` | 安装开机自启并后台启动 |
| `-Uninstall` | 卸载开机自启 |
| `-Status` | 查看运行状态 |
| `-Once` | 只登录一次 |
| `-Diagnose` | 网络与门户诊断 |
| `-SelfTest` | 本地自检（不访问门户） |
| `-FetchCrypto` | 重新下载门户加密脚本 |
| `-Logoff` | 注销下线（排查用） |
| `-Quiet` | 静默模式，不输出到控制台 |

调用方式：

```powershell
powershell -ExecutionPolicy Bypass -File lib\main.ps1 -Diagnose
```

## 六、关于 PowerShell 执行策略

Windows 默认会限制脚本运行，直接双击 `.ps1` 可能看到这样的错误：

```
无法加载文件 xxx.ps1，因为在此系统上禁止运行脚本
```

**本程序已处理这个问题**：所有 `.bat` 入口都使用
`powershell -ExecutionPolicy Bypass`，只对本次调用放宽限制，
**不会修改你的系统设置**。

如果你想手动运行，也请带上这个参数：

```powershell
powershell -ExecutionPolicy Bypass -File lib\main.ps1 -Status
```

> **说明**：`-ExecutionPolicy Bypass` 是微软官方提供的机制，
> 仅对当前这一次命令生效，不修改注册表，符合安全规范。
> 不建议使用 `Set-ExecutionPolicy Unrestricted` 这类全局修改。

## 七、常见问题排查

先运行这两个命令，多数问题能直接定位：

```powershell
powershell -ExecutionPolicy Bypass -File lib\main.ps1 -SelfTest    # 本地自检
powershell -ExecutionPolicy Bypass -File lib\main.ps1 -Diagnose    # 网络诊断
```

日志文件位置：`data\autologin.log`

### 1. 登录失败

| 现象 | 原因 | 解决办法 |
|---|---|---|
| `找不到配置文件` | 没做第 1 步 | 双击 `1-初始化配置.bat` |
| `配置文件还有必填项没有填写` | 还是模板里的占位文字 | 按第 1 步填写真实信息 |
| `配置文件格式错误` | JSON 语法错 | 检查是否用了中文引号、是否多了逗号 |
| `portal.base_url 还没填` | 地址没改 | 改成真实的门户地址，别带 `/index.html` |
| 返回码 `4`/`5` | 账号或密码错误 | 核对学号、密码；注意 `@` 等符号要完整 |
| 返回码 `255` 且 `msg=ARG` | 服务端要求附带参数 | 见下面第 3 条 |
| `门户不可达` | 不在校园网内 | 插网线或连校园 WiFi 后重试 |
| `Windows Script Host 不可用` | 系统文件被安全软件拦截 | 把程序目录加入安全软件白名单 |
| `无法从门户加密脚本中解析出密钥` | 自动解析失败 | 见下面第 4 条 |
| 一直显示「认证中」 | 账号欠费 / 多地登录被踢 | 检查是否其他设备也在用同一账号 |

### 2. 提示需要 Node.js？

**不需要。** 本版本已经用 Windows 自带的
**Windows Script Host（cscript.exe）** 替代了 Node.js，
全程不需要安装任何软件。

如果你看到任何提示要装 Node.js，说明用的是旧版本，请使用本版本。

### 3. 返回码 255、提示 `ARG`

服务端要求请求的 URL 上带 AC（接入控制器）传来的参数。做法：

1. 用**浏览器**在校园网下打开认证页面
2. 把地址栏里 `?` 后面的内容**整段复制**，例如：
   `wlanuserip=你的客户端地址&wlanacname=AC-01&nasip=你的网关地址`
3. 粘贴到配置文件的 `portal.query` 里：

```json
"portal": {
  "query": "wlanuserip=你的客户端地址&wlanacname=AC-01&nasip=你的网关地址"
}
```

### 4. 无法解析出加密密钥

程序会先从门户的加密脚本里自动找密钥。找不到时手动指定：

1. 浏览器打开 `<门户地址>/assets/js/crypto.js`，另存到本地
2. 用记事本打开，搜索 `parse`，找到形如
   `parse('0123456789abcdef')` 的 16 位十六进制字符串
3. 填到配置文件的 `crypto.key`

> 每所学校的密钥不同，以你自己门户里的为准。

### 5. 开机自启没生效

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 重启后没有日志 | 自启项没装上 | 双击 `4-查看状态.bat`，看「计划任务」是否「已安装」 |
| 计划任务已安装但没运行 | 触发条件是「登录时」 | **必须真正登录进桌面**才会启动，属正常现象 |
| 创建任务报「拒绝访问」 | 被组策略/安全软件拦截 | 程序已自动降级到启动文件夹；仍失败请把程序目录加入白名单 |
| 换电脑或改了用户名 | 任务里记录的 SID 变了 | 重新双击 `2-安装开机自启.bat` |
| 移动了程序目录 | 自启记录的是绝对路径 | 移动后必须重新运行 `2-安装开机自启.bat` |

**手动兜底（最可靠）**：按 `Win + R` 输入 `shell:startup` 打开启动文件夹，
新建一个文本文件，内容如下，另存为 `CampusAutoLogin.vbs`：

```vbscript
Set sh = CreateObject("WScript.Shell")
sh.CurrentDirectory = "你的程序完整目录"
sh.Run "powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File ""你的程序完整目录\lib\main.ps1"" -Quiet", 0, False
```

### 6. 频繁断连 / 反复重连

| 现象 | 原因 | 解决办法 |
|---|---|---|
| 每隔几十秒就重连 | 探测目标响应慢，导致误判 | 调大 `offline_trigger` 到 `3`；或换 `connect_test_url` |
| 认证成功但马上掉线 | **多地/多设备同时在线**，被 AC 互相踢号 | 只保留一台设备登录 |
| 掉线后很久才恢复 | 重试间隔太长 | 把 `retry_interval` 改成 `5` |
| 每次重连失败但能上网 | 门户会话状态短暂不一致 | 属正常，可把 `session_check` 设为 `0` 减少干扰 |
| 休眠/睡眠后掉线 | 网卡节能 | 在电源选项里关闭网卡节能 |

**推荐调参**（在 `config.json` 里改）：

```json
"keepalive": {
  "check_interval": 60,
  "offline_trigger": 3,
  "retry_interval": 5
}
```

### 7. 日志越来越大

日志已内置轮换：超过 1MB 自动转为 `autologin.log.1`，最多占 2MB。
可改 `runtime.log_max_bytes`，或直接删除 `data\autologin.log`。

### 8. 怎么彻底卸载

1. 双击 `3-卸载开机自启.bat`
2. 删除整个程序文件夹

程序**不写注册表、不装系统服务、不修改任何网络配置**，
删除文件夹后系统里不会留任何东西（除计划任务外，而它已被第 1 步删除）。

## 八、工作原理（了解即可）

```
启动 → 能上网? ──是──→ 每隔 N 秒检测一次 ──通──→ 继续
                 │                        │
                 否                      连续失败达阈值
                 ↓                        ↓
           执行登录流程 ←──────────── 判定掉线，重新登录
                 │
           失败则隔 N 秒重试，直到成功
```

**认证流程**（与浏览器完全一致）：

```
POST {门户}/api/login.php     提交 账号 + 加密口令 + 认证模式
POST {门户}/api/stat.php      轮询认证结果（返回码 0 或 3 表示成功）
POST {门户}/api/ack_auth.php  认证成功后的回执
```

**两个关键设计：**

1. **口令加密用系统自带能力实现**
   门户提交密码前会用自带的私有算法加密。本程序**不重写该算法**
   （算错就会导致密码错误），而是：
   - 从门户下载它自己的 `crypto.js` 并缓存到 `data\`
   - 用系统自带的 **Windows Script Host** 执行该脚本
   - 得到与浏览器**逐字节一致**的密文

   经实测比对，其输出与用 Node.js 执行的结果完全相同。

2. **连通性检测校验内容，而不是只看能否 ping 通**
   程序请求一个可信小文件并**核对返回内容**，
   这样能识别出「网络被门户劫持到登录页」的情况。

**三段式适配（提升兼容性）**：
若门户接口返回异常，程序会依次尝试：
方案 1 标准 UTF-8 表单 → 方案 2 GBK 编码 → 方案 3 系统自带 `curl.exe`。

## 九、低版本系统备选方案

若你的系统**低于 Windows 10 1709**（PowerShell 低于 5.1），有两种选择：

| 方案 | 做法 | 说明 |
|---|---|---|
| **升级系统** | 升级到 Windows 10/11 | 最省事，推荐 |
| **手动升级 PowerShell** | 安装 WMF 5.1 | 需从微软官网下载，属于"安装软件"，本程序不推荐也不提供 |
| **改用 Python 版** | 见另一版本程序 | 需要安装 Python 环境 |

> 本程序的设计目标是**零安装**，所以无法在过老的系统上保证可用。
> 请以自检结果为准：`-SelfTest` 会明确告诉你系统组件是否满足要求。

## 十、安全与隐私

**本程序做了什么：**
- 只用标准 HTTP 请求模拟浏览器登录
- 把自己的日志和缓存写在程序目录的 `data\` 子目录
- 注册一个属于当前用户、可一键卸载的计划任务

**本程序不做什么：**
- ❌ 不修改网卡、驱动、DNS、路由等任何网络配置
- ❌ 不读取、不上传账号密码到任何第三方（只提交给学校门户本身）
- ❌ 不含任何恶意行为、信息窃取、系统破坏逻辑
- ❌ 不弹广告、不捆绑安装
- ❌ 不需要关闭杀毒软件

**⚠️ 隐私提醒：**
`config\config.json` 里是**明文账号密码**（这是自动登录所必需的）。
**请勿把这个文件发给别人，也不要上传到网盘、GitHub 等公开位置。**
